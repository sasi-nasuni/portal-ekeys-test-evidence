# PORTAL-3183 — GET encryption keys Swagger evidence

**187 scenarios passed; 696 original Swagger screenshots.**

Portal PR: [nasuni/portal#2793](https://github.com/nasuni/portal/pull/2793). Tested revision: `3486973db7258c29ac419f0e624e08016885c55d`. Captured 2026-10-05 against the local API.

Requests were sent through Swagger UI’s **Try it out / Execute**. Long responses have multiple screenshots covering every scroll position. Bearer credentials are masked in screenshots and redacted in JSON; all account, key, volume, and task records are synthetic.

Coverage: escrowed/non-escrowed keys, escrow permission/license combinations, backup access, feature and permission denial, all supported filters and sorts, literal searches, task states/errors, cursor navigation and validation, independent iterators, creation cutoffs, and actual PostgreSQL tenant isolation (including foreign tasks with matching resource IDs).

Ten malformed-query scenarios used Swagger’s native `requestInterceptor` because its controls prevented entering those invalid values. These still reached the real server through Swagger and returned actual HTTP 422 responses. Each affected result documents this.
